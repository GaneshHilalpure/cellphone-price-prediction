#  Cellphone Price Prediction

##  Overview

This project predicts the price range of mobile phones based on features like RAM, battery power, camera, and connectivity.

##  Problem Statement

The goal is to help a mobile company estimate price categories (low, medium, high, very high) using machine learning.

##  Dataset Features

* Battery Power
* RAM
* Internal Memory
* Camera (Front & Primary)
* Connectivity (3G, 4G, WiFi, Bluetooth)

##  Steps Performed

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Selection
* Model Building (Logistic Regression, Random Forest, etc.)
* Model Evaluation

## Dataset

The dataset used in this project is available here:
https://d3ilbtxij3aepc.cloudfront.net/projects/CDS-Capstone-Projects/PRCP-1000-ProtugeseBank.zip

##  Results

* Achieved high accuracy in predicting price range
* Identified RAM and battery as key factors

* Scikit-learn
* Matplotlib, Seaborn
